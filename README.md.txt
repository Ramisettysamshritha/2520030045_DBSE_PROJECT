# Travel Package Booking Portal

## Project Overview

The Travel Package Booking Portal is a web-based travel management system designed to provide a single platform for exploring and booking travel packages and related services.

The system manages travel packages, destinations, hotels, rooms, buses, restaurants, bookings, payments and customer reviews through a relational database.

## Technologies Used

- React.js
- Node.js
- Express.js
- MySQL
- Mapbox
- Payment Gateway

## Main Features

- Package Catalog
- Itinerary Builder
- Dynamic Pricing
- Travel Package Booking
- Bus Booking
- Hotel Management
- Restaurant Management
- Vendor Management
- Payment Management
- Customer Reviews
- Sales Reports

## Database

Database Name:

### Main Tables

- Users
- Travel Packages
- Destinations
- Package Destinations
- Bookings
- Payments
- Hotels
- Rooms
- Buses
- Restaurants
- Reviews
